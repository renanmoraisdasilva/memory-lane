Scope-aligned screens built from the product specification and the review decisions. Click any screen to open the clickable prototype.

What changed: one shared shell, one combined photo/video viewer, manual-only dates, no advanced search or personal organization features, one Library health hub, and a drive drawer instead of a separate drive manager. Every v0.1 screen control maps to a planned v0.1 feature; the post-v0.1 replication preview is labelled separately.

Duplicate quarantine

info

Implemented in the duplicate quarantine release. One button keeps one copy per exact SHA-256 group and moves the rest to E:\.memorylane_quarantine\<run-id>\. Files are renamed, never permanently deleted. Back up and remove the folder manually, then rescan.

verified_user

Read-only by design (v0.1): every v0.1 screen uses catalog-only language. Actions that would touch the real filesystem show a prototype toast instead. Duplicate quarantine is the one implemented exception: it renames files into a quarantine folder only after explicit confirmation. The normal app remains read-only.
